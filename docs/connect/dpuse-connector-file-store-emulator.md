# File Store Emulator

Imitates a cloud-based file storage solution. It hosts a read-only set of files for demonstration, evaluation and testing purposes and is freely available to all users.

| Property | Value |
| -------- | ----- |
| Version | 0.2.497 |
| Category | File Store |
| Usage | Source |
| Status | Beta |

## Supported Operations

- Abort Operation
- Audit Object Content
- Find Object
- Get Readable Stream
- List Nodes
- Preview Object
- Retrieve Records

## Authentication

This connector uses **None required** authentication.
