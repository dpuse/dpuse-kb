# Dexie.js

Dexie.js is a compact, well tested wrapper for IndexedDB — the standard database in every browser.

| Property | Value |
| -------- | ----- |
| Version | 0.2.298 |
| Category | Database |
| Usage | Bidirectional |
| Status | Alpha |

## Supported Operations

- Abort Operation
- Create Object
- Drop Object
- Find Object
- Get Record
- List Nodes
- Preview Object
- Upsert Records
- Remove Records
- Retrieve Records

## Authentication

This connector uses **None required** authentication.
