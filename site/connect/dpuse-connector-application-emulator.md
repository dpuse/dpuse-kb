# Application Emulator

Imitates a hypothetical application database. It provides a read-only set of tables for demonstration, evaluation and testing purposes and is freely available to all users.

| Property | Value |
| -------- | ----- |
| Version | 0.0.9 |
| Category | File Store |
| Usage | Source |
| Status | Beta |

## Supported Operations

- Abort Operation
- Audit Object Content
- Find Object
- Get Readable Stream
- List Nodes
- Preview Object
- Retrieve Records

## Authentication

This connector uses **None required** authentication.
