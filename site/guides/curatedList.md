# Curated List

::: warning
Notes - not for publication.
:::

This is not an exhaustive list, but rather a list of commonly encountered visualisation libraries. Please feel free to notify us of any other libraries or corrections.

Basic chart types: Area, Bar, Bubble, Doughnut, Line (Spline, Step, Straight), Pie, Polar, Radar, Range (Area, Bar), Rose, Scatter, Spider.

Advanced chart types: Annotation, Bullet, Calendar, Candlestick, Chord, Cone, Dumbbell, Gantt, Gauge (Angular, Linear), Funnel, HeatMap, Histogram, Marimekko, Pyramid, Network, Sankey, Sparkline, Stock, Stream, TreeMap, Waterfall, WordCloud.

Advanced features: Grouped stacked bars.

Convert following list to table. Columns: npm, github, website addresses. Last release. Last modification. License type: Open Source, Commercial limited eval, Commercial open eval. Number of downloads. View types supported.

See https://cssauthor.com/javascript-charting-libraries/ for an exhaustive, but dated list. Find old lists.
